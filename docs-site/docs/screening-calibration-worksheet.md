# Screening Calibration Worksheet

Use this worksheet before title and abstract screening starts. The purpose is
to test whether reviewers apply the protocol in the same way before the full
screening batch begins.

Calibration is not a vote and it is not a shortcut to final eligibility. It is
a training and methods check. If reviewers disagree because the protocol is
unclear, fix the protocol before screening hundreds or thousands of records.

Do not choose only easy records. The sample should expose ambiguity before the
full screening batch starts.

## Disagreement Review

Discuss disagreements after independent screening. Do not erase the original
reviewer decisions. The disagreement is evidence that the team needs either a
shared interpretation or a protocol amendment.

| Disagreement type | Example question | Action |
| --- | --- | --- |
| Population ambiguity | Does this setting count as primary care? | Clarify the setting rule. |
| Intervention ambiguity | Does messaging count as digital coaching? | Define included intervention components. |
| Outcome ambiguity | Are process outcomes eligible? | Clarify eligible outcomes. |
| Study-design ambiguity | Is a protocol, feasibility study, or review eligible? | Clarify design and publication-type rules. |
| Missing abstract | Can the record move to maybe? | Define how missing abstracts are handled. |
| Duplicate or companion report | Is this the same study or a related report? | Record how companion reports will be handled. |

## Calibration Outcome

| Metric | Value |
| --- | --- |
| Records calibrated |  |
| Records with agreement |  |
| Records with disagreement |  |
| Criteria changed? | Yes / No |
| Protocol amended? | Yes / No |
| Ready for full screening? | Yes / No |

Agreement does not need to be perfect. The team should proceed when
disagreements are explainable, the protocol is clear enough to apply, and the
adjudicator knows how conflicts will be resolved.

## Ready To Start Screening

Start the full title and abstract batch only when all are true:

- reviewers understand the inclusion and exclusion criteria;
- the team agrees how to use **Include**, **Maybe**, and **Exclude**;
- missing abstracts have a documented handling rule;
- common disagreement types have an adjudication plan;
- any protocol amendments are recorded;
- the review lead approves starting the full batch.
