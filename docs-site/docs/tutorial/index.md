# Tutorial

This tutorial walks through the implemented Nexus Scholar workflow using the
real evidence example described in [Real Evidence Example](../demo-review.md).

Use it as a guided rehearsal for a research team:

1. Sign in and open the lab workspace.
2. Create the project and complete the protocol.
3. Build and run the search plan.
4. Inspect the corpus.
5. Deduplicate and lock the snapshot.
6. Screen titles and abstracts.
7. Retrieve legal open-access full text.
8. Screen full text and resolve eligibility conflicts.

The screenshots show one completed training run in the **Evidence Synthesis
Lab** workspace. If you are using a hosted instance, use the account and
workspace provided by your team. In a local evaluation environment, use the
owner account configured for that environment.

!!! tip "How to use this guide"
    Keep the guide open in one tab and Nexus Scholar open in another. Follow
    one page at a time. Stop at each checkpoint and confirm the visible counts
    before moving forward.

## Evidence Discipline

Do not screen records just to make the software move forward. For a real
review, each include, maybe, exclude, and conflict decision should be traceable
to the protocol criteria. The tutorial decisions are examples of how to record
that reasoning inside the product.
